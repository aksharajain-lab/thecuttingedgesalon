#  Cutting Edge Hair Salon

**A modern, responsive website designed for a premium hair salon — built to showcase its services, establish a strong digital presence, and turn visitors into potential customers.**

---

## ✦ About the Project

Cutting Edge Hair Salon is a modern business website concept created for a professional salon looking to establish a polished and engaging online presence.

The website focuses on presenting the salon's **services, atmosphere, and brand identity** through a clean visual experience while keeping essential information easy to discover.

The goal was simple:

> **Make the salon feel as good online as it does in person.**

---

## ✦ Key Features

* **Modern Landing Page** — Strong visual introduction to the salon and its identity.
* **Service Showcase** — Clear presentation of the salon's offerings.
* **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
* **Clear Navigation** — Simple structure that helps visitors quickly find relevant information.
* **Call-to-Action Sections** — Designed to guide visitors toward enquiries and appointments.
* **Visual Branding** — Consistent typography, spacing, imagery, and layout throughout the experience.

---

## ✦ Design Direction

The design was created around a **modern, sophisticated salon aesthetic**.

Rather than overwhelming visitors with information, the interface uses:

* Strong visual hierarchy
* Generous spacing
* Clean typography
* High-quality imagery
* Strategic calls to action
* A refined and contemporary layout

The objective was to create a website that feels **professional, premium, and approachable** while remaining easy to navigate.

This project was built as an exploration of **AI-assisted web development and real-world business design**.

## ✦ Running Locally

### Prerequisites

Make sure you have **Node.js** and **npm** installed.

### Installation

```bash
git clone <repository-url>
cd <repository-name>
npm install
npm run dev
```

The development server will start locally and provide a URL for viewing the website.
